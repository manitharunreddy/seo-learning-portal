LESSON 13

HTTP Status Codes

Whenever you open a website, your browser sends an HTTP request to the server. The server responds with a status code that indicates what happened to that request.

HTTP status codes are important in technical SEO because they help us understand whether pages are accessible, redirected, missing, or experiencing server problems.

1. What Is an HTTP Status Code?

An HTTP status code is a three-digit number returned by a server to describe the result of an HTTP request.

For example:

  • 200 OK: The request succeeded.
  • 301 Moved Permanently: The URL moved permanently.
  • 302 Found: The URL is temporarily redirected.
  • 404 Not Found: The requested resource was not found.
  • 500 Internal Server Error: The server encountered an unexpected problem.

2. HTTP Status Code Categories

  • 1xx — Informational: The request is being processed.
  • 2xx — Success: The request was successfully received and processed.
  • 3xx — Redirection: The client needs to take further action, usually by following a redirect.
  • 4xx — Client Error: There is a problem with the request.
  • 5xx — Server Error: The server failed to complete a valid request.

3. Status Code 200 — OK

A 200 OK response means the request succeeded.

Imagine a visitor opens our What Is SEO? lesson. If the server successfully returns the requested page, the response will normally have a 200 status code.

SEO importance:

  • Confirms that the page was served successfully.
  • Helps search engines access the page content.
  • Important pages intended for indexing should generally return a successful response.

4. Status Code 301 — Permanent Redirect

A 301 Moved Permanently response indicates that a URL has permanently moved to another URL.

For example, suppose an article moves from an old URL to a new URL. A 301 redirect can send visitors and search engines to the new destination.

SEO importance:

  • Helps search engines understand permanent URL changes.
  • Can consolidate relevant ranking signals toward the destination.
  • Internal links should be updated to point directly to the new URL.

Use a 301 redirect when the move is permanent and a suitable destination exists.

5. Status Code 302 — Temporary Redirect

A 302 Found response indicates a temporary redirection.

For example, a website might temporarily redirect visitors while a page is undergoing maintenance.

SEO importance: Search engines may treat temporary redirects differently from permanent redirects. Choose the status code that matches your actual intention.

6. Status Code 400 — Bad Request

A 400 Bad Request response means the server cannot process the request because it considers the request invalid.

This may happen when a request contains malformed data or invalid syntax.

SEO importance: If search engine crawlers receive 400 errors when requesting important pages, investigate the requests and server configuration.

7. Status Code 403 — Forbidden

A 403 Forbidden response means the server understood the request but refused access.

For example, a server may block access because the requester does not have permission to view a resource.

SEO importance: If public pages that should be accessible to search engines return 403, check permissions, security rules, and firewall settings.

8. Status Code 404 — Not Found

A 404 Not Found response means the requested resource could not be found.

Imagine a lesson file is renamed, but another page still links to the old filename. The old link may return a 404 error.

SEO importance:

  • Fix internal links that point to missing pages.
  • Restore pages that were deleted accidentally.
  • Redirect a moved page when a relevant replacement exists.
  • Allow genuinely removed pages to return 404 when there is no suitable replacement.

A 404 response is not automatically an SEO problem. Search engines expect some URLs to be missing. The important thing is to handle them correctly.

9. Status Code 500 — Internal Server Error

A 500 Internal Server Error response means the server encountered an unexpected condition and could not complete the request.

Possible causes include:

  • Application exceptions.
  • Server configuration problems.
  • Unexpected failures while processing a request.

SEO importance:

  • Investigate server and application logs.
  • Fix errors that prevent important pages from loading.
  • Monitor whether the problem happens repeatedly.
  • Verify the status code after fixing the issue.

10. Quick Comparison

Status Code Meaning Typical Action
200 OK Confirm the page content is correct.
301 Permanent Redirect Update internal links to the final URL.
302 Temporary Redirect Confirm the redirect is temporary.
400 Bad Request Investigate invalid requests.
403 Forbidden Check access rules and permissions.
404 Not Found Fix broken links where appropriate.
500 Internal Server Error Investigate server and application logs.

11. How to Check an HTTP Status Code

You can check a page's HTTP status code using your browser's Developer Tools.

  1. Open the page you want to inspect.
  2. Press F12 to open Developer Tools.
  3. Select the Network tab.
  4. Reload the page.
  5. Select the main document request.
  6. Look for the HTTP status code in the request details.

You can also use Google Search Console to investigate indexing problems and inspect how Google accesses a URL.

12. Practical Example Using Our Website

Imagine you open our SEO-Friendly URLs lesson.

  • If the page loads successfully, it will normally return 200.
  • If the page permanently moves, the old URL can return 301.
  • If the page has been removed without a replacement, it can return 404.
  • If the server encounters an unexpected failure, it may return 500.

As an SEO developer, your job is to identify unexpected status codes and fix the underlying problems.

13. Lesson Takeaway

HTTP status codes tell browsers and search engines what happened when a URL was requested. Understanding these codes helps you diagnose crawling, accessibility, redirection, and server problems.

Always investigate unexpected status codes instead of assuming every error requires the same solution.
