LESSON 17

Image SEO

Bro, images make a website attractive, but poorly optimized images can slow down your pages and make it harder for search engines to understand what the images represent. Image SEO helps you optimize images for users and search engines.

1. What Is Image SEO?

Image SEO means optimizing website images so they load efficiently, provide useful information, improve accessibility, and can be understood by search engines.

Simple definition: Image SEO is the process of making your images accessible, relevant, and efficient for your website.

2. Why Is Image SEO Important?

  • Optimized images can help improve page loading speed.
  • Descriptive alt text helps people using screen readers.
  • Search engines can better understand the context of images.
  • Relevant images can appear in image search results.
  • Properly displayed images improve the user experience.

3. Use Descriptive Image Filenames

Before uploading an image, give it a meaningful filename that describes its content.

Less useful filename: IMG001.jpg

Better filename: chocolate-birthday-cake.jpg

Use short, descriptive filenames and separate words with hyphens. Avoid stuffing filenames with repeated keywords.

4. Add Appropriate Alt Text

The alt attribute provides a text alternative for an image. It is particularly useful for people who use screen readers and when an image cannot be displayed.

Example:

<img
  src="../assets/chocolate-birthday-cake.jpg"
  alt="Chocolate birthday cake decorated with strawberries"
>

Use alt text that accurately describes the image in its context. Don't force keywords into alt text when they do not naturally describe the image.

When should alt text be empty?

If an image is purely decorative and adds no meaningful information, use an empty alt attribute so assistive technologies can skip it. 

<img src="../assets/decorative-divider.png" alt="">

5. Choose the Right Image Format

  • JPEG: Commonly used for photographs.
  • PNG: Useful when lossless quality or transparency is needed.
  • WebP: Often provides smaller files with good visual quality.
  • AVIF: Can provide highly efficient image compression in supported browsers.
  • SVG: Useful for scalable logos, icons, and vector illustrations.

Choose a format based on the image type, quality requirements, browser support, and file size.

6. Compress Images

Large image files take longer to download, particularly on slower internet connections. Compression reduces file size while aiming to preserve acceptable visual quality.

Before adding an image to your website:

  1. Check its file size.
  2. Resize it to appropriate dimensions.
  3. Compress it using a suitable method.
  4. Check the result to ensure the image still looks good.

7. Use Responsive Images

Responsive images allow browsers to choose an appropriate image source for the visitor's screen and display requirements.

Example using srcset and sizes:

<img
  src="../assets/product-medium.jpg"
  srcset="../assets/product-small.jpg 480w,
          ../assets/product-medium.jpg 800w"
  sizes="(max-width: 600px) 100vw, 800px"
  alt="A product displayed on a table"
>

This example assumes the corresponding image files exist in your project's assets folder. Replace the filenames with actual files from your project before using the code.

8. Set Image Dimensions

Providing image dimensions helps browsers reserve space before an image finishes loading. This can reduce unexpected layout shifts. 

<img
  src="../assets/product.jpg"
  alt="Product displayed on a table"
  width="800"
  height="600"
>

Use the image's actual dimensions or dimensions that correctly represent its aspect ratio.

9. Lazy Loading Images

Lazy loading allows images outside the initial visible area to load when they are approaching the user's viewing area. 

<img
  src="../assets/gallery-image.jpg"
  alt="A product in the gallery"
  loading="lazy"
>

This can reduce unnecessary initial loading work. However, avoid lazy loading the main image that is immediately visible when the page loads, especially if it is the page's largest contentful image.

10. Image SEO Mistakes to Avoid

  • Using unclear filenames for important images.
  • Leaving meaningful images without appropriate alt text.
  • Adding keywords that do not describe the image.
  • Uploading unnecessarily large image files.
  • Stretching images and changing their aspect ratio.
  • Using image paths that point to files that do not exist.
  • Lazy loading the main image that should load immediately.
  • Using important text inside images without providing that information as page text.

11. Practical Task

Bro, open your own SEO learning portal and inspect the images used throughout your website.

  1. Check whether each image has an appropriate filename.
  2. Verify that meaningful images have descriptive alt text.
  3. Check whether large images can be compressed.
  4. Confirm that image paths point to existing files.
  5. Check whether images fit correctly on mobile screens.

12. Quick Revision

  • Use descriptive filenames.
  • Write useful alt text for meaningful images.
  • Choose suitable image formats and compress files.
  • Use responsive images when appropriate.
  • Specify image dimensions to help prevent layout shifts.
  • Use lazy loading for suitable off-screen images.
