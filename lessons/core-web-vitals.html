LESSON 18

Core Web Vitals

Bro, imagine opening a website. The page takes too long to display its main content, a button responds slowly, or the layout suddenly moves while you're trying to click something. These problems create a poor user experience.

Core Web Vitals are Google's key metrics for measuring important aspects of the real-world experience users have when loading and interacting with a webpage.

1. What Are Core Web Vitals?

Core Web Vitals are a set of performance metrics that measure loading performance, responsiveness, and visual stability.

Simple definition: Core Web Vitals help us understand how quickly a page displays its main content, responds to user interactions, and stays visually stable.

2. The Three Core Web Vitals

There are three key metrics:

  • LCP: Largest Contentful Paint — loading performance.
  • INP: Interaction to Next Paint — responsiveness.
  • CLS: Cumulative Layout Shift — visual stability.

3. LCP — Largest Contentful Paint

LCP measures how long it takes for the largest visible image or text block in the viewport to render.

Friend explanation: Page open chesinappudu, user ki important ga kanipinche main content entha fast ga display avuthundo LCP help chesthundi.

LCP thresholds

  • Good: 2.5 seconds or less.
  • Needs improvement: More than 2.5 seconds and up to 4 seconds.
  • Poor: More than 4 seconds.

Common causes of poor LCP

  • Slow server response times.
  • Large, unoptimized images.
  • Render-blocking CSS or JavaScript.
  • Slow loading of important resources.

How to improve LCP

  • Improve server response time.
  • Compress and resize large images.
  • Load the main above-the-fold image promptly.
  • Reduce unnecessary render-blocking resources.
  • Use caching and a content delivery network where appropriate.

4. INP — Interaction to Next Paint

INP measures how responsive a page is to user interactions, such as clicks, taps, and keyboard input, throughout a visit.

Friend explanation: Bro, button click chesinappudu website response ivvadaniki ekkuva time theeskunte, user ki website slow ga anipisthundi. INP ee responsiveness ni measure chesthundi.

INP thresholds

  • Good: 200 milliseconds or less.
  • Needs improvement: More than 200 milliseconds and up to 500 milliseconds.
  • Poor: More than 500 milliseconds.

Common causes of poor INP

  • Long-running JavaScript tasks.
  • Too much JavaScript running on the main thread.
  • Expensive event handlers.
  • Complex rendering and layout calculations.

How to improve INP

  • Remove unnecessary JavaScript.
  • Break up long-running tasks.
  • Optimize click and input event handlers.
  • Avoid unnecessary DOM updates.
  • Keep interactions responsive while other work runs.

5. CLS — Cumulative Layout Shift

CLS measures unexpected visual movement of page content during the page's lifespan.

Friend explanation: Bro, nuvvu oka button click cheyyabothunte sudden ga page content move ayi, wrong button click ayithe, adi layout shift problem avvachu.

CLS thresholds

  • Good: 0.1 or less.
  • Needs improvement: More than 0.1 and up to 0.25.
  • Poor: More than 0.25.

Common causes of poor CLS

  • Images without reserved dimensions.
  • Advertisements or embeds inserted without reserved space.
  • Content injected above existing content.
  • Web fonts that cause visible layout changes.

How to improve CLS

  • Specify image width and height.
  • Reserve space for ads and embedded content.
  • Avoid inserting new content above existing content unexpectedly.
  • Choose font-loading strategies that minimize layout changes.

6. Quick Comparison

Metric Measures Good Score
LCP Loading performance ≤ 2.5 seconds
INP Responsiveness ≤ 200 milliseconds
CLS Visual stability ≤ 0.1

7. Are Core Web Vitals a Ranking Factor?

Core Web Vitals are part of Google's page experience signals. Good scores can contribute to a better user experience, but they do not guarantee higher rankings.

Relevant, useful content and many other factors also influence search rankings. Don't sacrifice content quality just to improve a performance score.

8. How to Check Core Web Vitals

You can assess performance using browser developer tools and Google's performance reporting tools.

  • Laboratory data: Measurements collected in a controlled testing environment.
  • Field data: Measurements collected from real users under real-world conditions.

Lab tests are useful for debugging. Field data helps you understand how your website performs for actual visitors. Results may differ because devices, networks, and user interactions vary.

9. Practical Task

Bro, test your SEO learning portal and inspect these three areas:

  1. LCP: Identify the main visible content and check whether it loads quickly.
  2. INP: Test whether navigation links and lesson completion buttons respond smoothly.
  3. CLS: Watch whether the layout unexpectedly shifts while the page loads.

Also check that images have dimensions and that unnecessary JavaScript does not delay interactions.

10. Quick Revision

  • LCP measures loading performance.
  • INP measures responsiveness.
  • CLS measures visual stability.
  • Real-user data and lab tests provide different insights.
  • Good Core Web Vitals improve user experience but do not guarantee rankings.
