LESSON 14

Robots.txt and XML Sitemaps

Search engines need to discover your website pages and access their content to understand them. Two important technical SEO concepts are robots.txt and XML sitemaps.

Although they work differently, both can help you manage how search engines interact with your website.

1. What Is robots.txt?

A robots.txt file gives instructions to compliant search engine crawlers about which URL paths they may or may not crawl on a website.

It is usually located at the root of a website.

Example location:

https://example.com/robots.txt

The address above is only an illustrative example, not a link to a page in your project.

2. Example of a robots.txt File

Imagine you want to allow search engine crawlers to access your website. 

User-agent: *
Allow: /

Here's what the instructions mean:

  • User-agent: * applies the rule to all crawlers that follow these rules.
  • Allow: / allows crawling of URLs on the website, subject to other applicable rules and restrictions.

This is a simple example. Real websites may need different rules depending on their structure and requirements.

3. Blocking a Directory with robots.txt

Suppose a website has a directory containing internal application resources that should not be crawled.

An illustrative rule might look like this:

User-agent: *
Disallow: /private-area/

This asks compliant crawlers not to crawl URLs matching that path.

Important: Do not copy this rule into your SEO learning website without a specific reason. It is only an example of how the directive works.

4. What robots.txt Cannot Do

  • It is not access control: It does not protect private files or prevent unauthorized visitors from accessing them.
  • It does not guarantee deindexing: A blocked URL may still appear in search results if discovered through other sources.
  • It does not force every crawler to obey: Malicious crawlers may ignore its instructions.
  • It does not guarantee indexing: Allowing a crawler to access a page does not mean that the page will appear in search results.

If a page contains confidential information, use proper authentication and authorization rather than relying on robots.txt.

5. What Is an XML Sitemap?

An XML sitemap is a file that lists important URLs on a website to help search engines discover them.

It is particularly useful for large websites, websites with many pages, and pages that are not easily discovered through internal links.

A sitemap commonly uses the XML format and may be named sitemap.xml.

6. Example of an XML Sitemap

Here's a simplified sitemap example:

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">

  <url>
    <loc>https://example.com/</loc>
  </url>

  <url>
    <loc>https://example.com/about/</loc>
  </url>

</urlset>

The URLs above are illustrative examples, not actual pages in your project.

Understanding the XML Elements

  • <urlset>: The root element containing the URL entries.
  • <url>: Represents one URL entry.
  • <loc>: Contains the absolute URL of the page.

A sitemap may include additional information, but optional fields should only be used when they are accurate and useful.

7. robots.txt vs XML Sitemap

Feature robots.txt XML Sitemap
Main purpose Provides crawling instructions Lists URLs for discovery
Typical filename robots.txt sitemap.xml
Common location Website root Website root or another permitted location
Blocks crawling? Can request that crawlers avoid matching paths No
Helps discover URLs? Not its primary purpose Yes
Guarantees indexing? No No

8. How Do Search Engines Use Them Together?

Imagine your website contains many useful pages.

  1. The search engine discovers your website.
  2. It checks robots.txt for applicable crawling instructions.
  3. It may discover URLs through internal links and an XML sitemap.
  4. If crawling is permitted, it can request a page and process its content.
  5. The search engine decides whether the page should be indexed and how it should appear in search results.

Remember that crawling, indexing, and ranking are different processes. Neither robots.txt nor a sitemap guarantees that a page will be indexed or rank highly.

9. Common SEO Mistakes

  • Blocking important pages accidentally in robots.txt.
  • Assuming robots.txt protects confidential information.
  • Listing incorrect or nonexistent URLs in a sitemap.
  • Including URLs that redirect or return errors instead of their intended final pages.
  • Forgetting to update the sitemap when important URLs change.
  • Assuming that submitting a sitemap guarantees indexing.
  • Using robots.txt when the actual requirement is to prevent a page from appearing in search results.

11. Lesson Takeaway

robots.txt provides crawling instructions to compliant crawlers, while an XML sitemap helps search engines discover important URLs.

Use both correctly, keep your sitemap accurate, and make sure important pages are connected through relevant internal links.
