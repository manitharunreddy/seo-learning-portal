LESSON 12

Internal Linking

Internal linking is an important part of SEO. It helps search engines discover pages on your website and helps visitors navigate between related topics.

In this lesson, we'll learn how internal links work, why they matter, and how to implement them correctly in your website.

1. What Is Internal Linking?

An internal link connects one page of your website to another page on the same website.

For example, your SEO learning website contains separate lessons about SEO basics and keyword research. You can connect these lessons using internal links.

Example:

<a href="keyword-research.html">Learn Keyword Research</a>

This link connects the current lesson to the Keyword Research lesson because both files are inside the same lessons folder.

Remember: The link above is an HTML example. You should use it on a page where keyword-research.html is the correct relative path.

2. Why Are Internal Links Important?

  • Page discovery: Search engines can discover other pages by following links.
  • Navigation: Visitors can move between related pages without returning to the homepage every time.
  • Context: Links help search engines understand how different pages relate to one another.
  • Link equity: Internal links can help distribute ranking signals across relevant pages on your website.
  • User experience: Visitors can discover additional information related to the topic they're reading.

3. How Do Internal Links Work?

Imagine your website has this structure:

SEO Zero to Hero
        |
        |---- What Is SEO?
        |
        |---- Keyword Research
        |        |
        |        |---- Search Intent
        |        |
        |        |---- Long-Tail Keywords
        |
        |---- SEO-Friendly URLs
        |
        |---- Internal Linking

Each lesson covers a different topic. When relevant links connect these lessons, visitors can easily move from one topic to another.

Search engines can also follow these links to discover pages and understand their relationships.

Important pages should be reachable through useful links rather than being left without any internal links pointing to them.

4. What Is Anchor Text?

Anchor text is the visible, clickable text inside a hyperlink.

Example:

<a href="what-is-seo.html">Learn SEO Basics</a>

In this example, Learn SEO Basics is the anchor text, and what-is-seo.html is the destination.

Because both files are in the same folder, this relative path is suitable when the link is placed inside another lesson in that folder.

Good anchor text describes the destination clearly. Avoid vague phrases such as "click here" when a more descriptive phrase would help visitors understand the link.

5. Best Practices for Internal Linking

  • Link to pages that are relevant to the current content.
  • Use descriptive and natural anchor text.
  • Make important pages easy to discover through navigation and contextual links.
  • Connect related lessons so visitors can continue learning.
  • Check internal links regularly to identify broken destinations.
  • Maintain a logical website structure.
  • Update internal links when you rename or move a page.
  • Avoid adding links that do not provide value to the reader.

6. Bad vs Good Internal Linking

Bad Example

Read our article about SEO. Click here.

The link works, but "Click here" does not clearly describe the destination.

Better Example

Start with our What Is SEO? lesson to understand the fundamentals of search engine optimization.

The anchor text describes the destination, making the link more informative for visitors.

Both examples point to the same existing lesson. The difference is how clearly the anchor text describes the destination.

7. What Is a Broken Internal Link?

A broken internal link points to a page that cannot be found or accessed correctly.

For example, imagine a lesson file is renamed, but another lesson still links to its old filename. Clicking that link may return a 404 error.

To prevent broken links:

  • Use the correct filename and relative path.
  • Update links whenever you rename or move a lesson file.
  • Restore a page if it was deleted accidentally.
  • Redirect an old URL when a page has permanently moved and a suitable replacement exists.
  • Test your links in the browser after making changes.

A 404 response is not automatically an SEO problem. The important thing is to handle missing pages correctly and avoid linking visitors to destinations that should be available.

8. Common Internal Linking Mistakes

  • Linking to unrelated pages.
  • Using unnatural, keyword-stuffed anchor text.
  • Leaving important pages difficult to discover.
  • Ignoring broken internal links.
  • Adding excessive links that distract visitors.
  • Forgetting to update links after renaming files.
  • Using incorrect relative paths.

9. Practical Example Using Our SEO Lessons

Our SEO learning website contains several lessons that can be connected naturally.

For example, while explaining keyword research, you could direct visitors to related lessons:

  • Search Intent explains what users want when they search.
  • Long-Tail Keywords explains longer, more specific search phrases.
  • Keyword Mapping explains how to assign keywords to appropriate pages.

These links connect related topics and help visitors follow a logical learning path.

Notice that the links use only lesson filenames from our existing project. Since these files are in the same folder, we do not need to add ../ before their filenames.

10. Relative Paths: Avoiding 404 Errors

Understanding relative paths is especially important when building a static website.

Linking Between Lesson Files

When the current file and destination file are both inside the lessons folder, use the destination filename: 

<a href="keyword-research.html">Keyword Research</a>

Linking to the Homepage

The homepage is one folder above the current lesson file, so use:

<a href="../index.html">Home</a>

Linking to the Lessons Section

To navigate to the lessons section on the homepage, use:

<a href="../index.html#lessons">All Lessons</a>

Important: A relative path must match your actual folder structure and filename. Always test the destination in your browser.

11. Lesson Takeaway

Internal linking connects pages within your own website. Relevant links, descriptive anchor text, and a logical structure help visitors navigate your content and help search engines discover and understand the relationships between your pages.

As a developer, always verify your link paths and make sure the destination files actually exist.
