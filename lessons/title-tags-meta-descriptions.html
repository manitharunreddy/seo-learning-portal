LESSON 09

Title Tags & Meta Descriptions

In this lesson, we will learn how to write effective HTML title tags and meta descriptions for search engines and website visitors.

1. What Is a Title Tag?

A title tag defines the page title in the HTML document. Search engines may use it as the clickable headline in search results.

Example:

<title>Petrol Bunk Management Software | Petrosoft</title>

This tells search engines and users what the page is about. The title should accurately describe the page content.

2. What Is a Meta Description?

A meta description is a short summary of a webpage included in its HTML metadata. Search engines may use it as the descriptive text beneath the title in search results.

Example:

<meta name="description" content="Manage petrol bunk billing, fuel stock, daily sales, and reports with easy-to-use management software.">

Important: Google may generate a different search snippet from the page content. Writing a meta description does not guarantee Google will display it exactly as written.

3. Title Tag vs Meta Description

  • Title tag: Describes the page and may appear as the clickable search result headline.
  • Meta description: Summarizes the page and may appear below the headline.

4. How to Write an SEO-Friendly Title

  1. Describe the page content accurately.
  2. Include the main topic or keyword naturally.
  3. Make the title unique for each important page.
  4. Keep it clear and useful to searchers.
  5. Avoid unnecessary keyword repetition.
  6. Avoid misleading claims and clickbait.

Example of a weak title:

<title>Home</title>

A more descriptive title:

<title>Petrol Bunk Billing Software | Petrosoft</title>

There is no guaranteed ideal character limit. Google may shorten or rewrite titles depending on the device, search query, and available display space.

5. How to Write a Good Meta Description

  1. Summarize the actual page content.
  2. Explain what the visitor can learn or do.
  3. Use the main topic naturally.
  4. Make the description specific and useful.
  5. Avoid copying the same description across every page.
  6. Do not stuff the description with keywords.

Example of a weak description:

<meta name="description" content="Welcome to our website.">

A more useful description:

<meta name="description" content="Explore petrol bunk billing software for managing fuel sales, inventory, payments, and daily business reports.">

6. Real-Time Example

Imagine you are creating a pricing page for petrol bunk software. Your HTML head section might look like this: 

<head>
  <meta charset="UTF-8">

  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <title>Petrol Bunk Software Pricing | Petrosoft</title>

  <meta
    name="description"
    content="Explore petrol bunk software pricing and compare features for billing, fuel inventory, and sales reporting."
  >
</head>

The title identifies the page's main topic, while the description gives searchers a useful preview of its content.

7. Common Mistakes to Avoid

  • Using the same title on every page.
  • Leaving important pages with vague titles.
  • Writing descriptions unrelated to the page content.
  • Repeating keywords unnaturally.
  • Making promises the page cannot deliver.
  • Assuming Google must display your exact title and description.

Key Takeaway

Title tags and meta descriptions help communicate what a page offers. Write a unique, accurate title and a useful description for every important page.

Remember: Title tags are important for SEO. Meta descriptions are not a direct Google ranking factor, but a well-written description may help searchers understand the page and decide whether to visit it.
